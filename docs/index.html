Copyshot

Press Print Screen. That's it.

A tiny Windows screenshot tool that lives in the tray. Every capture is saved as a PNG and copied to your clipboard, ready to paste.

Download for Windows View on GitHub

640 × 360

Features

  • Drag to capture a region, with a live size readout
  • Capture just the active window
  • Capture every monitor at once
  • Saved to Pictures\Screenshots and copied to the clipboard
  • Sharp at any display scaling, across multiple monitors
  • A quiet chime confirms each capture (can be turned off)
  • Starts with Windows and stays out of the way
  • Updates itself from GitHub releases

Controls

Capture a regionPrint Screen or double-click the tray icon
Capture the active windowAlt + Print Screen
Capture the full desktopShift + Print Screen
Cancel a selectionEsc or right-click
SettingsRight-click the tray icon
